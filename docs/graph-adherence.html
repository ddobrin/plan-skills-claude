Conformance

Three assertions, and where the swarm now stands against each

Assertion 01

The topology is an explicit artifact

Which nodes exist, what routes between them and under what condition — readable as one thing, not inferred from prose.

was · three prose copies, drifted
now · one declaration, diagrams generated

plugins/plan/graph.json declares 16 nodes, 25 edges, 2 gates and every node's contract. Both README lifecycle diagrams are generated from it between BEGIN/END GENERATED markers. graph.py sync --check fails if either is stale.

Assertion 02

Each node gets its own clean context

Different prompts, different tools, different evidence per node, so one agent's working memory does not pollute another's.

was · already satisfied
now · extended inside the panels

Per-node isolation was already the swarm's strongest property. What was missing was isolation within a fan-out: the three skeptics of each panel shared one prompt. They now hold three lenses and three reading assignments.

Assertion 03

State crosses boundaries only through declared edges

A schema, not a directory convention. The phase is read, not re-derived.

was · convention, phase inferred
now · declared, phase read

state.json per milestone (lib/graph/STATE.md) records phase, gate decisions, per-node status and per-group commits. reads/writes/must_not_write live in graph.json and are machine-checked.

One deliberate deviation

The original recommendation put reads:/writes: contracts in each skill's frontmatter. They went into graph.json instead. Putting them in both places would create a second hand-maintained copy of the same facts — which is precisely the defect assertion 1 exists to prevent. One declaration, checked against disk, is the stronger reading of the same intent.

Assertion 01 · mechanism

The diagram is an output now, not a document

The check is not decorative. It fails on a declared skill or agent missing from disk, an edge pointing at an unknown node, an unreachable node, a node claiming write authority it does not have, a panel whose declared lens count disagrees with its prompt file — and specifically on a prompt file that has reverted to dispatching identical skeptics.

Assertion 02 · mechanism

Context isolation, extended inside the fan-out

The swarm already isolated context per node. It did not isolate context within a node's fan-out: each panel dispatched one prompt three times, so the three branches shared a prompt, a model and a reading assignment. The topology said three votes; the information said roughly one.

PanelLens 1Lens 2Lens 3
spec-validator internal-consistency

the diff vs. its description		 failure-paths
error branches and tests		 blast-radius
call sites not in the diff

Each panel now ships a shared preamble, three lens sections and a shared tail, and each run must first pass the asymmetry test — name one finding only that lens could reach; if you cannot, merge it and run two. That test is borrowed verbatim in spirit from plan-deliberator's Core Principle 1, which had it right all along.

Findings now carry a lens field, so the join records which lenses agreed. cross_lens agreement — two lenses reaching one finding from different evidence — ranks above two votes from readers who saw the same material.

Assertion 03 · mechanism

The phase is read, not re-derived

Honest accounting

What this does not claim

  • The highest-value change is not graph engineering. Lens partitioning satisfies assertion 2, but the reason to do it comes from the correlated-judge literature, not from any topology principle. A graph can be perfectly explicit and still route three identical opinions.
  • No runtime was adopted. No LangGraph, no dynamic workflow, no scripted orchestration. Everything here is a declaration file, a stdlib script, and prompts — so it behaves identically on Claude Code and Antigravity, which is the constraint a workflow-based gate would have broken.
  • The join is still a model. Extracting the quorum tally to a script was ranked below this work and is not in this branch. Measured, it is worth about a point; the lens partition is where the eight-to-twenty-two points live.
  • Nothing is measured yet. The claim that partitioned lenses find more than identical ones is an inference from the literature until you re-run a shipped milestone both ways and diff the confirmed sets. That is the next thing to do, not the thing that has been done.
